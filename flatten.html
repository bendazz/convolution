What is Flattening?

The output of the last conv/pool block is a 3D tensor (height × width × channels). A fully-connected layer expects a 1D vector, so we flatten — reshape the 3D block into a single row of numbers by concatenating every value from every channel end-to-end. All information is preserved; only the spatial structure is discarded.

Why So Many Parameters?

Each FC neuron has one weight for every element of the flattened vector, plus a bias. With a 4×4×8 tensor (128 values) and 64 neurons, that is 128×64 + 64 = 8,256 parameters — just for one layer. This is why CNNs use pooling and strided convolutions to shrink the tensor before flattening: smaller tensors mean dramatically fewer FC parameters.
