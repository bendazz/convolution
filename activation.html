Why Bias?

The bias is a learnable parameter added to each convolution output. It shifts the activation function's input, allowing the neuron to activate (or stay inactive) even when the weighted sum of inputs would otherwise be zero. Each filter in a convolutional layer has its own bias value.

Why Non-linearity?

Without activation functions, stacking multiple convolution layers would collapse into a single linear transformation — no matter how deep the network. Non-linear activations allow the network to learn complex patterns like curves, textures, and object boundaries that linear operations alone cannot capture.
